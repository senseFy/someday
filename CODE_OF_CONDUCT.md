# Code of Conduct

Someday is built in public for people who value thoughtful, dependable
software. Everyone participating in this repository is expected to help keep
the project welcoming, constructive, and safe.

## Expected behavior

- Treat people with respect, including when technical opinions differ.
- Critique ideas and code with specific evidence; do not attack the person.
- Make room for different backgrounds, experience levels, languages, and
  communication styles.
- Respect privacy. Do not publish another person's private information, logs,
  credentials, or personal note data.
- Accept maintainer decisions about scope and moderation without harassment.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, sustained
disruption, deliberate intimidation, doxxing, and knowingly malicious
technical contributions are not tolerated.

## Reporting and enforcement

Report conduct concerns privately through the repository owner's GitHub
profile contact options. Do not open a public issue containing sensitive
personal information. Security vulnerabilities follow the separate
[Security Policy](SECURITY.md).

Maintainers may edit or remove contributions, restrict participation, or ban
accounts when necessary. Responses should be proportionate to the behavior,
its impact, and whether harmful conduct continues after a clear warning.

This policy applies in project spaces and when someone is officially
representing the project elsewhere.
